# STUDY

과제 README의 추가 파일·AI 사용 제한을 우선한다. 학습 세션은 이 양식으로 학습 기록만 작성한다. 코드와 요구사항·결정·검증 기록 구역은 원래 담당자가 관리하며 학습 세션이 수정하지 않는다.
설명은 실제 코드·데이터·검증 결과와 기록된 판단을 근거로 한다. 근거 없는 개발 이유·사용자 판단·답변·이해 완료를 만들지 않는다.

학습 상태: 미실행 / 설명 작성 / 답변 대기 / 보완 필요 / 설명 확인. 설명 확인은 본인의 실제 답변을 현재 코드·기록과 대조한 경우에만 사용한다.
코드·업무 규칙·검증 결과가 바뀌면 영향받는 기능과 최종 설명 확인을 갱신 필요로 표시한다. 기능별로 아래 구역을 추가하고, 같은 요구는 기준 버전과 내용을 갱신해 중복을 줄인다.
