# 합성 모의 과제: 노선 관리 웹 서비스

이 README와 `data/`만 먼저 읽는다. evaluator/는 현업 담당자/평가자 전용이다.
공식 시험 문제가 아닌 독립적인 연습 과제다. 예상 개발 시간은 180분이며 스택은 자유다.

## 업무 배경

운영 담당자는 제공된 CSV를 바탕으로 노선과 정류장 구성을 확인하고 노선 이름/운행 여부를 관리하려 한다.
원본에는 여러 시스템에서 추출한 중복과 불완전한 행이 섞여 있다. 파일 행 순서를 정답으로 가정하지 않는다.

## 필수 요구사항

| ID | 기능/제약 | 완료조건 |
|---|---|---|
| R-01 | CSV 프로파일링·검증 | 스키마·행 수·결측·중복·이상값·키·관계·변환 손실을 보고하고 오류를 숨기지 않는다. 원본 불변 |
| R-02 | 노선 목록 | 이름 부분검색, 운행 여부 필터, 노선 ID/이름/운행 여부/정류장 수/검증 상태 표시 |
| R-03 | 노선 상세 | 업무상 유효한 경유 순서와 정류장 정보를 표시. 공유/반복 정류장을 정확히 취급 |
| R-04 | 정류장 역조회 | 정류장 ID로 경유 노선 목록을 조회. 운휴 노선 포함 여부·오류 노선 취급은 현업 확인 |
| R-05 | 노선 편집 | 이름과 운행 여부 수정. 잘못된 입력 거부, 새로고침/서버 재시작 뒤 유지. 원본 CSV 불변 |
| R-06 | 데이터 품질 표시 | 제외·중복제거·격리 근거와 행 번호(헤더 제외 1부터), 입력/처리 후 수지를 확인 가능 |
| R-07 | 실행·검증·설명 | 실행 가능한 웹 서비스, AGENTS.md, CONTRACT.md, CONTROL.md, 테스트와 실제 명령/결과 |

CSV 파일은 `routes(route_id,name,active)`, `stops(stop_id,name)`, `route_stops(route_id,stop_id,sequence)`다.
active의 원본 표기는 `true`/`false`다. route_stops의 한 행은 경유 지점으로 보이지만 정확한 관측 단위와 정책은 확인해야 한다.
노선/정류장 생성·삭제, 지도·좌표·시간표, 로그인, 원본 수정, 실시간 협업은 범위 밖이다.

## 현업 담당자에게 확인할 수 있는 항목

충돌하는 식별자·경유 순서, 반복/공유 정류장, 결측/참조 오류의 처리, 검색/편집 제약을 데이터 근거와 함께 질문한다.
관찰한 실제 행을 제시해 Golden Case를 요청할 수 있다. 질문 전에 정답 파일을 열지 않는다.
기술적 사실과 업무 결정을 구분하고 미응답을 임의로 확정하지 않는다.

## 제출/검증

README의 R-01~07에 추적 가능한 AC를 만들고 실제 실행 결과를 남긴다.
원본 해시 전후 비교와 행 수지를 포함한다. 테스트 통과와 브라우저 수동 검증 여부를 구분한다.
별도 Reviewer를 사용할 수 없으면 역할을 전환해 반례를 실행하고 독립성 한계를 명시한다.
정답/해설을 이미 읽었다면 블라인드 평가나 실제 시험 성능으로 해석하지 않는다.

## 제공된 완성 예시 실행 (첫 분석 이후)

```powershell
python app.py --port 8765
# http://127.0.0.1:8765
python profile_data.py
python rehearsal/verify.py --stage final
python evaluator/score.py
```

완성 예시는 Python 3.10+ 표준 라이브러리만 사용한다. 편집 결과는 output/state.json에 저장되고 Git에 포함되지 않는다.
로컬 단일 프로세스 연습용이다. 인터넷 공개 배포는 이 과제 범위 밖이다.
공식 실행 기록은 위 verify.py로 수집한다. 원시 unittest의 종료 0만으로는 검사 0개/전부 skip을 구분할 수 없다.
제공 가이드의 플랫폼 Browser 흐름을 연습할 때는 `python app.py --host 0.0.0.0 --port 8765`로 실행하고 PORT=8765, 경로=/를 지정한다.
이 옵션은 준비용 예시이며 Private 예제의 실전 반입 허용을 뜻하지 않는다. 기본 실행은127.0.0.1이고 실제 플랫폼 화면 동작은 별도 확인한다.
