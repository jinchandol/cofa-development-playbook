# 합성 현업 인터뷰

실제 외부 담당자에게 문의한 것이 아니다. evaluator/RULES.md의 시나리오 답변을 사용하는 리허설이다.
질문 원문은 ANALYSIS.md Q1~Q6. 답변 제공자가 분석/작성자와 동일하므로 질문 발견 성능의 독립 지표로 사용하지 않는다.

| Q | 답변/근거 | 구현 변경·확정 |
|---|---|---|
| Q1 | B-01: 다른 순번의 재방문 유지. Golden R1=S1,S2,S1,S3 | stop_id로 경유 중복제거 금지, (route,sequence,stop) 동일 행만 접기 |
| Q2 | B-03: 완전동일만 접기, 속성 충돌 키 전체 격리 | R3 전체 격리, S3 1건 유지, last-write-wins 금지 |
| Q3 | B-04: 유효 마스터/경유를 먼저 확인한 뒤 실제 순번 충돌 노선의 전체 경유 격리 | R2 blocked, 목록 유지/경유0, R1의 SX 가짜 충돌은 제외 |
| Q4 | B-05: 잘못된 행만 격리, 원래 순번 유지 | 원본 불변, 각 원본 행 disposition과 진단 코드 |
| Q5 | B-02: 운휴 포함, blocked 경유 제외, 노선별 1건 | Golden S3→R1,R4, 반복 S1→R1 1건 |
| Q6 | B-06/07: trim+casefold 검색, 이름 1~80자, JSON bool, 파생 상태 유지, 운행 수정으로 blocked 해제 불가 | 엄격 입력 검증, output/state.json, 원자 교체 |

이번 고정 데이터 범위의 미응답 업무 정책은 없다. 새로운 스키마/일자별 경유/노선 버전 충돌 정책은 범위 밖이며 일반화하지 않는다.
